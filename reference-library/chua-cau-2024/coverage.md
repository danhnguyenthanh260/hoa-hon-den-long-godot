# Chua Cau 2024 reference coverage

Status: first source set reviewed; hero-model coverage is incomplete.

## Intended use

- Hero architecture evidence for the rebuilt Chua Cau.
- Post-2024-renovation appearance only; historical variants require a separate
  dated source set and must not be mixed silently.
- Source series: Chainwit., CC BY 4.0, Wikimedia Commons.

The first set is useful for silhouette, restored palette, canal opening rhythm,
both portal ornaments, context, and lighting. File 11 is a Snapseed-processed
variant and is not authoritative material color. The set is not suitable for
photogrammetry or a four-side reconstruction. It also contains identifiable
people; copyright is CC BY 4.0, but public redistribution remains pending a
separate personality-rights decision. No geometry may pass the measured-model
gate while any required coverage or dimensions remain `missing`.
