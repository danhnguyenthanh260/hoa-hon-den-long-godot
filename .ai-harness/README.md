# Hoa Hon Den Long Project Overlay

This repository owns all project-specific rules for the Godot game.

## Project contract

- Engine: Godot 4.5, Forward+ renderer.
- Current production target: original 60-90 minute cinematic 3D experience based on Script v3.
- `Do You Copy?` is a reference only for slow-burn pacing, audio/radio interaction, constrained agency, and helplessness. Do not copy its plot, characters, dialogue, encounter structure, or distinctive assets.
- Real-world reference assets require recorded source, author, license, retrieval date, allowed use, and redistribution status before they enter a distributable build.
- AI-generated geometry is never authoritative for measured heritage architecture, structural joins, navigation-critical geometry, hero props, or final human anatomy.
- A green parse/build is not completion. Delivery requires rendered visual checks, gameplay observation, performance evidence, provenance validation, and independent QA.
- Preserve all work that predates the active task. Do not reset or overwrite dirty files to simplify implementation.

## Source-of-truth order

1. `.state/index.md` and the active task card for resumability pointers.
2. Current git/remote state and the working tree for implementation truth.
3. `docs/SCRIPT-v3.md`, `docs/SCRIPT-v3-EXPERIENCE.md`, and `docs/SCRIPT-v3-PHAN-CANH.md` for the intended experience.
4. Production plans, asset manifests, validation reports, and runtime evidence created for the active task.

## Required gates

1. Provenance and license gate.
2. Reference coverage and scale gate.
3. Modeling topology, join, UV, material, collision, and LOD gate.
4. Four-side plus 360-degree turntable visual gate.
5. Godot import, navigation, lighting, and performance gate.
6. Narrative state, audio, accessibility, save/recovery, and regression gate.
7. Independent reviewer gate; the implementing agent cannot be the sole approver.
